## Projects

**[flybrain-reservoir](https://github.com/MilanKalajdzic/flybrain-reservoir)**: Is a real fly brain a better reservoir computer than random wiring? The full *Drosophila* connectome (166,700 neurons) as an echo state network for SPY returns and volatility, tested against four null-model wirings. Short answer: no. It has no market edge over random wiring, and at whole-brain scale it remembers far less. Python, PyTorch (GPU), pytest, CI.

**[ETF-Trend-Predictor](https://github.com/MilanKalajdzic/ETF-Trend-Predictor)**: Next-day trend direction for European ETFs (IEUR, FEZ, EUFN) from ~260 technical indicators, with MLP and LSTM models under walk-forward validation. Reproducible pipeline in Python and Docker with Quarto reports. Started as a team project, extended solo.
